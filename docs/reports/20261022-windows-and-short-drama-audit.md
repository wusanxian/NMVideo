当前 `desktop/package.json` 是 0.1.1，前端 dist 修改于 10 月 21 日，小说改编模块也晚于上述产物。最新找到的 0.1.1 安装包仍不能代表当前源码的发布版本；本次未实际安装验证。

确认的交付问题：

1. **旧版更新清单不匹配**：顶层 `desktop/dist/latest.yml` 指向英文名 0.1.0 安装包，但其 size/SHA512 对应中文名安装包。实际计算 SHA512，英文名文件不匹配，中文名文件匹配。如照此上传，会导致更新校验失败。子目录 0.1.1 的清单校验正常，不能把旧版问题泛化为全部构建。
2. **版本分散**：桌面壳 0.1.1、旧安装包 0.1.0、启动器固定 1.0.0、后端 API 0.2.0；缺少统一的产品版本与构建来源标识。
3. **根目录没有明显成品入口**：exe 藏在两层 dist 内，README 没有把“当前验收版”和旧构建清晰区分。
4. **安装包不是离线完整包**：启动器首次运行仍安装 Python/torch/依赖及模型；Electron 默认启动参数不带 `--no-download`，即便只准备连接外部 ComfyUI，也会经过本地环境与模型准备流程。
5. **构建脚本有空实现**：`packaging/build.py` 的 `build_frontend()` 是 `pass`，主流程只检查已有前端产物，不保证是最新源码。根目录 `build-desktop.bat` 会先构建前端，可以绕过这一问题，但单独运行 Python 构建脚本可能包入旧页面。

建议先完成一次可追溯的新版本构建，保留一个清晰的发行目录，包含安装包、校验值、更新清单、版本说明和启动说明；新机器验证首次安装、中文路径、启动/停止、升级保留项目，再对外发布。

## 3. 影响短剧成片的缺口

| 优先级 | 缺口 | 当前证据与实际影响 | 建议完成标准 |
|---|---|---|---|
| P0 | 配音可能被截断，多条对白缺少逐句排程 | `export.py::_mix_audio` 把每条配音放在镜头起点并裁到镜头长度；同镜头多条配音会同起点混合 | 说话人、句子、起止时间独立保存；超时明确提示，允许延长镜头/重配语速/人工修正；不能静默丢失对白 |
| P0 | 缺少完整的竖屏成片规格 | `ExportCreate` 只暴露 fps；导出宽高取第一段视频；分镜生成接口高度上限 768 | 项目与导出明确支持 9:16、16:9、1:1；统一画布、裁切策略、字幕安全区；支持选择 1080×1920 输出（不等同于原生生成画质） |
| P0 | 新版本交付与真实出片验收不足 | 构建产物落后，更新清单校验不一致；单元测试不能证明模型实拍质量 | 新机从安装到完整带对白成片验收；给出可运行样片及版本/工作流/硬件记录 |
| P1 | 角色跨镜头与跨集一致性仍依赖具体工作流 | 本地 AnimeDiff/Wan 生成函数注明不使用参考图；视觉条件主要在支持它们的 ComfyUI/FreeVideo 流程使用 | 确定一条经实测的角色参考图/LoRA 出片路径；固定人物、服装、场景参考，跨镜头检查；避免把文本角色卡等同于视觉稳定性 |
| P1 | 缺少表演级配音与口型流程 | TTS 当前主要为 edge-tts/SAPI5；未发现内建口型同步、克隆音色和情绪表演控制流程 | 逐句角色配音、试听/采用版本、情绪/停顿控制，再接入支持的口型工作流；漫剧旁白模式可先交付，人物对话模式另行验收 |
| P1 | 字幕没有按实际语音对齐 | `routers/assets.py::auto_subtitles` 按镜头起止时间挂整段对白 | 按语音时间戳或对齐结果分句，支持人工调轴、断行、样式与安全区 |
| P1 | 审核尚未覆盖画面与声音质量 | `shotcheck.py` 主要检查提示词、参考图、版本和文件存在性 | 增加黑帧/静帧/音频缺失/对白超时等确定性检测；人物漂移、闪烁、口型偏差用视觉检测辅以人审 |
| P1 | 缺少整集音画一体的生产编排 | 小说批次 UI 主要控制视频生成；配音、字幕、混音和导出仍是分散操作 | 审核后串起配音→时长校验→视频生成/采用→字幕→混音→导出，支持失败节点恢复 |
| P2 | 剪辑与混音能力较基础 | 已有列表式时间线、裁切、轨道音量与 amix；未发现自动压低背景音乐、响度统一和语音波形编辑 | 增加波形与逐句排程、对白优先混音、响度和峰值控制；需要时提供剪辑软件工程交换 |
| P2 | 成本和系列化交付统计不足 | 批次预算是按质量和镜头时长乘固定基准估算秒数，非实际 API 金额 | 记录各服务调用/实际耗时/失败重试成本；按集统计；提供系列统一资产、封面、片头片尾与分集导出管理 |

## 4. 建议实施顺序

1. 先把当前版本可靠地做成 Windows 发行物，修复更新清单并验证新机启动。
2. 先补对白不截断、多角色逐句排程、字幕对齐、竖屏规格，保证完整成片可交付。
3. 固定一套真实验证的角色一致性工作流，再补情绪配音与口型同步。
4. 用一集 60–90 秒、2 名角色、8–12 个镜头、带音乐和字幕的样片验收全链路，再推进多集自动化。

本次未进行真实模型推理或安装旧 exe。功能“已有”表示源码入口存在，不能据此推断所有模型与外部服务已在此机器上可用。
