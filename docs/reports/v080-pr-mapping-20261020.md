## 二、本批三处实施明细

### 批一 `4053e4d` fix(PR-02)：ComfyUI 上传唯一文件名
- 问题：`ComfyUIClient.upload_image` 未显式命名时用原始文件名 + `overwrite=true`；ComfyUI input 目录共享，不同任务上传同名素材（如各镜头抽帧默认名 `frame_0001.png`）互相覆盖，先提交的工作流执行时读到别人的图。
- 修法：`name` 为空时自动加 12 位 uuid 前缀（`{uuid12}_{原名}`）；显式名不改写（向后兼容）。返回的 `data["name"]` 与工作流引用天然一致。
- 测试：`test_upload_unique_name.py` 4 例（前缀生成/两次上传不碰撞/显式名保留/失败抛错）。

### 批二 `0ee9e55` feat(PR-04)：required_models 模型扫描
- `workflow_capabilities.py`：`capability_from_template` 新增 `required_models` 字段；`check_missing_models` / `missing_models_from_info` / `_iter_loader_options`——从 `/object_info` 全量响应收集各 loader 节点的选项清单（即已装模型列表），basename 精确匹配；探测失败或响应无 loader 选项 → `([], False)` 不虚构。
- 生成侧：`generate_shot` 在缺节点检查后追加未装模型检查 → 400 明示（"需要以下模型但未安装"），不留 job。
- capabilities 端点：全量 object_info 只拉一次共享，每条目新增 `missing_models` / `models_probe_ok` / `models_probe_done`。
- 预设声明（文本级 Edit，不重排 JSON）：`wan_ti2v` 声明 3 个模型文件（`wan2.2_ti2v_5B_fp16.safetensors` / `umt5_xxl_fp8_e4m3fn_scaled.safetensors` / `wan2.2_vae.safetensors`）；`anime_diff` 声明 2 个（SD1.5 checkpoint + `mm_sd_v15_v2.ckpt`）；MiniMax 付费 API 不声明本地模型。
- 前端：ComfySetupView 依赖模型 chips（缺失标红）+ 「未安装 N 个模型」红色警示 / 「已安装」/ 离线提示。
- 测试：+6 例（含端点与生成阻断端到端）。

### 批三 `3f5305b` feat(PR-06)：导出帧率参数化
- db 第六批轻量迁移：`projects.fps INTEGER DEFAULT 24`、`exports.fps INTEGER DEFAULT 0`（0=旧记录），建表 schema 同步。
- `create_export(project_id, fps=None)`：显式 > 项目帧率 > 24，创建时冻结（运行中改项目不影响进行中导出）。
- `run_export`：`exp.fps(0) → project.fps(无效) → 24` 三级回落传给 `concat_videos`，删除硬编码 `fps=16`（`video.py` 的默认参数保留，由调用方显式传值）。
- 路由：`POST /projects/{id}/export` 可选 body `{"fps": N}`，pydantic 校验 8–60；`PATCH /projects/{id}` 白名单加 fps。
- 前端：时间线页导出按钮旁帧率下拉（16/24/30，默认 24），store/api 透传。
- 测试：`test_export_fps.py` 7 例（API 默认/项目/显式/非法 + worker 冻结帧率传递 + 旧记录回落）。
